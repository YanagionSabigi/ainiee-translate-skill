# LaTeX 后端设计与写作规范

以下将既有后端代码、数学排版和格式校正规范合为一个长有序列表，保留原有示例。正文标点服从[标点符号](标点符号.md)及项目预设；代码可读性与数学记号约定独立适用。
生成的 LaTeX 代码需遵循以下排版限制：

1. 正文标点服从 `预设参数.md` 的 full/half 选择，公式内部固定半角。以下列出半角模式的对应形式：
           + 使用 `,` 而非 `，`,
           + `;` 而非 `；`,
           + `.` 而非 `。`,
           + `!` 而非 `！`,
           + `?` 而非 `？`,
           + `(` 而非 `（`, `)` 而非 `）`,
           + 而允许使用顿号 `、` 与破折号 `——`.

2. 行间公式末尾也要加标点符号, 按公式在句子中的作用决定逗号、句号或其他标点, 多行推导通常在整体末尾处理. 对分段函数, 则在分段处使用分号, 示例为:
    ```LaTeX
    \chi_{[0, 1]}(x) = \begin{cases}
     1, & x\in [0, 1];
     \\
     0, & \text{其他}.
    \end{cases}
    ```

3. 半角 TeX 单引号使用一个反引号开头、一个撇号结尾；双引号使用两个反引号开头、两个撇号结尾。全角引号使用 `‘…’` 和 `“…”`。

4. 中文与西文、数字及数学公式之间应有 1 个空格；数字与单位不加空格，长数字每三位分组。

5. 半角结尾标点后接正文时加 1 个空格，正文前接该标点不加空格；标点组、成对符号及全角模式按[标点说明](标点符号.md)处理。

6. 除非在数学公式或表格中, 否则不要使用 `\\` 进行换行.

7. 注意区分 `-`、`--`、`---` 或 `—`.
        + `-` 是连字符, 用于单词中, 例如 well-known, 或连接同一姓氏的不同部分, 例如 Levi-Civita.
        + `--` 是短横线, 用于连接两个人名, 例如 Newton--Leibniz, 或连接两个数字, 例如 1--10.
        + `---` 或 `—` 是长横线, 用作破折号. 中文破折号由两个长横线构成, 即 `------` 或 `——`.
        + 以上三者都不能作为减号或负号. 因此, 在行文中提到数字时, 总应放在数学公式中, 如`$-1$`.

8. 代码中不能有过长的行. 每行尽量不超过 80 个字符.

9. 环境的内容 (`\begin` 和 `\end` 之间) 使用 4 个空格缩进.

10. `\[` 与 `\]` 各占一行, 它们之间的内容用 4 个空格缩进.

11. `\item` 独占一行, 它的内容用 4 个空格缩进, 如下:
        ```LaTeX
            \begin{itemize}
                \item
                ...
            \end{itemize}
        ```

12. 数学公式中, 应多加空格, 尤其在二元运算符与反斜杠指令之间. 例如: `$1 + 1 = 2$`, `$f(x, y)$`.

13. 代码需要能够轻松地被别人阅读和修改.
        错误示例:
        ```LaTeX
        \[A=\begin{pmatrix}a_{11}&a_{12}\\a_{21}&a_{22}\end{pmatrix}.\]
        ```
        正确示例:
        ```LaTeX
                \[
                    A =
                    \begin{pmatrix}
                        a_{11} & a_{12}
                        \\
                        a_{21} & a_{22}
                    \end{pmatrix} .
                \]
        ```

14. 表示绝对值使用的竖线是 `|`, 但用描述法写集合时, 中间的分隔符要么使用冒号 `:`, 要么使用 `\mid`, 例如 `$\{x : x > 0\}$` 或 `$\{x \mid x > 0\}$`，而需要使用大型竖线时, 可使用 `$\big|$` 的方式控制.

15. 表示比值的冒号是 `:`, 但 f:X→Y 中的冒号是 `\colon`, 即 `$f\colon X\to Y$`.

16. 定义符号使用 `\coloneqq` 而非 `:=`, 使用 `\eqqcolon` 而非 `=:`.

17. 诸如像集、核、余核之类的符号正体使用 `$\operatorname{…}$` 而不使用 `$\mathrm{…}$`.

18. 少用定界符 `\left` 与 `\right`, 主要考虑以下情况:
        - 对行间的巨符号如 `\bigcup`, `\sum`, `\bigotimes`, `\oiiint` 等, 其很可能只有下标, 而定界符会增添额外的上标距离, 故这种情况应当手动设定括号为 `$\bigg(…\bigg)$` 一类.
        - 对分式或其他情形, 可以使用定界符.





19. 矩阵使用圆括号格式, 故矩阵使用 `pmatrix` 环境, 即形如:
        ```LaTeX
            \begin{pmatrix}
            1 & 0
            \\
            0 & 1
            \end{pmatrix}
        ```

20. 表示元素张成向量空间、生成子模等等时, 用尖括号包围, 譬如 `$\langle\vec{u}, \vec{v}\rangle$` .

21. 集合的包含关系采用 `$\subseteq$` 而非 `$\subset$`, `$\supseteq$` 而非 `$\supset$`.

22. 对非典型的偏序关系, 使用 `\preccurlyeq` 或 `\succcurlyeq` 符号来定义.

23. 对正规子群, 采用 `\vartriangleleft` 这个符号, 而对于子群, 采用 `\le` 这个符号.

24. 对域扩张, 采用斜杠记号, 即形如 `$F/k$` 的记号表 $F$ 是 $k$ 的扩域.

25. 对较长的公式推导排版, 如无引用必要, 使用 `align*` 行间公式排版, 在等号处换行. 并根据需要, 用颜色标记复杂的指标变换, 在第三列用灰色字体写明这行等式的依据, 如以下例子:
        ```LaTeX
            \begin{align*}
            (a + b)^{ n + 1 } & = (a + b)(a + b)^{ n } \\
            & = (a + b)\sum^{ n }_{ k = 0 }\binom{ n }{ k } a^{n - k} b^k & \color{gray}\text{归纳假设}
    \\
            & = \sum^{ n }_{ k = 0 }\binom{ n }{ k } a^{n + 1 - k} b^k + \sum^{ n }_{ k = 0 }\binom{ n }{ k } a^{n - k} b^{k \color{red} + 1} & \color{gray}\text{分配律}
    \\
            & = \sum^{ n }_{ k = 0 }\binom{ n }{ k } a^{n + 1 - k} b^k + \sum^{n{\color{red} + 1}}_{ k = \color{red} 1 }\binom{ n }{k\color{red} - 1} a^{n{\color{red} + 1} - k} b^{ k } & \color{gray}\text{求和指标平移}
    \\
            & = \binom{ n }{ 0 } a^{ n + 1 } b^{ 0 } + \left[\sum^{ n }_{ k = 1 }\bigg[\binom{ n }{ k } + \binom{ n }{k - 1}\bigg]a^{n + 1 - k} b^k\right] +  \binom{ n }{n} a^{ 0 } b^{ n + 1 }
    \\
            & = \binom{ n + 1 }{ 0 } a^{ n + 1 } b^{ 0 } + \sum^{ n }_{ k = 1 }\binom{ n + 1 }{ k } a^{n + 1 - k} b^k + \binom{ n + 1 }{ n + 1 } a^{ 0 } b^{ n + 1 }&\color{gray}\text{计算引理}
    \\
            & = \sum^{ n + 1 }_{ k = 0 }\binom{ n + 1 }{ k } a^{n + 1 - k} b^k
        \end{align*}
        ```

26. 对于运算过长, 以至于要在运算符处断行的长公式, 在运算符之前断行, 且添加 `\quad` 补偿相应的等号、同构号的间隔, 例如:
        ```LaTeX
                \begin{align*}
                \sum^{10}_{n=1} n & = 1+2+3+4+5
    \\
                & \quad +6+7+8+9+10
    \\
                &= 55
                \end{align*}
        ```

27. 标记对象间的态射时, 使用 `\xrightarrow{…}` 指令, 例如 `$X\xrightarrow{\varphi}Y$`.

28. 在行间写态射定义时, 用 `\longrightarrow` 而非 `\to` 或 `\rightarrow`, 用 `\longmapsto` 而非 `\mapsto`.

29. 在对元素进行罗列时, 使用 `\dots` 或 `\ldots` 作为省略号, 而对运算进行罗列时, 用 `\cdots` 作为省略号, 例如 `$1, 2, 3, \dots, 100$` 与 `$1 + 2 + 3 + \cdots + 100$`.

30. 在非微分几何的语境下, 向量一般写作列向量, 但列向量主要写在行间公式, 在行内写成行向量的转置. 用黑体如 `$\mathbf{a}$` 而非向量 `$\vec{a}$` 作为表示向量的符号.

31. 微分符号使用正体, 即使用 `$\mathrm{d}$` 的写法.

32. 对张量场, 采用 Penrose 指标与 Einstein 求和约定.

33. 积分常数 `$C$`, 自然对数的底数 `$e$` 与纯虚数单位 `i` 与四元数纯虚数单位 `$i,j,k$` 虽然是常数但均不使用正体.

34. 对组合数与二项式系数, 可根据语境(组合或代数的语境)使用 `$\mathrm{C}^r_n$` 或 `$\binom{n}{r}$` 的写法.

35. 对上极限与下极限, 使用 `\varlimsup` 与 `\varliminf` 符号.

36. 对范畴论中的极限, 使用 `\varinjlim` 与 `\varprojlim` 指令.

37. 在首次介绍一个新概念时，突出中文名称并附英文，例如 `\emph{二项式系数} (binomial coefficient)`。若需要外层引号，服从项目选定的引号形式；直角引号仅在明确启用时使用。

38. 表示集合的势时, 使用 `$\operatorname{card}(X)$` 或 `$|X|$`, 若对有限集, 亦可使用 `$\# X$`.

39. 对于由公式符号如 $n$-tuple, $p$-adic , $R$-模, 主 $G$-丛时，相应的公式符号与后面接续的概念之间用短横 `-` 连接.

    当用户作出校对格式的命令时, 依次执行以下工作:

40. 检查全文是否有错别字.

41. 检查全文的标点符号是否正确.

42. 检查全文的空格间距是否正确.

43. 按照以上规则修正行文.

44. 检查行文能否通过 LaTeX 编译.
