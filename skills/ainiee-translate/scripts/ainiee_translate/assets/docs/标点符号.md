# 标点符号与空格

中文译文有两种标点模式：全角模式 `full` 使用中文常见标点，适合一般中文阅读；半角模式 `half` 使用西文常见标点，适合需要统一西文标点的学术文本。默认全角。两种模式只决定排印形式，不改变原句语义；正文、标题、引文、注释、图注和表格文字采用同一约定。

在翻译模组的 `预设参数.md` 中选择模式。PDF 结构项目还须将选择同步到 `review.json` 的 `structure_rules.punctuation_mode`。输出格式另行选择，选 LaTeX 不等于自动切换半角。

| --- | --- | --- | --- |

| 句号 | `。` | `.` | |
| 分号 | `；` | `;` | |
| 冒号 | `：` | `:` | |

## 特殊说明

1. 汉字字符与英文、数字之间保留合适的一个半角空格，例如 `采用 Newton 方法`、`共 30 页`。边界跨越斜体、链接或公式图片时也要保留实际空格，不能只靠页面样式制造间距。
2. 半角标点的空格规则是：正文字符（汉字、拉丁字母、数字）后接逗号、句号、冒号等半角结尾标点时不加空格，半角结尾标点后接正文字符时加一个空格。例如 `结果为 3, 接着计算.`。相邻标点构成一组时不在组内插空格，空格放在整个标点组之后：`他说: "好." 随后离开.`。段末不补尾随空格。
3. 成对符号按开闭关系处理，括号和引号内部边缘不插空格：半角模式可写 `解释 (附注) 后继续`、`他说: "你好."`。开括号、开引号后不套用“加空格”的结尾标点规则；词内连字符和连接号也不按句末标点处理。
4. 数字与单位之间不加空格，例如 `30℃`、`50kg`、`99%`、`100£`。这是本项目采用的排印约定；货币符号的位置仍以原文含义与项目约定为准。单位组合与相邻汉字之间仍按第 1 条处理，例如 `重 50kg 的物体`。
5. 全角标点与其他正文字符之间不加空格，例如 `结果为 3，随后继续。`。固定使用的顿号、中文破折号也不因半角模式而另加空格。语义连接中的 `-`、`–` 两侧不额外加空格。
6. 长数字从个位向左每三位用空格分组，例如 `1 145 141 919 810`。年份、页码、编号、版本号和代码标识符按其用途保留，不能把 `2026` 年机械改成 `2 026` 年；小数点和符号的含义也须保留。
7. 中文／英文与行内公式之间保留一个空格；公式紧接标点时不再插空格。公式内部的语义标点一律半角，正文模式不影响 TeX 命令、负号或运算符。连字符 `-`、连接号 `–`、破折号 `——` 与数学减号分开处理。
8. 小数 `3.14`、网址、代码、英语词内撇号、文件名及 TeX 语法不作普通句末标点替换。引号须成对且嵌套清晰；OCR 的符号语义不清时回看原页，不按字形猜改。省略、并列或引文边界应保留原意。
9. 术语表的译名、说明、术语组合同样遵循这些空格和横线规则；源文识别字段保留实际源文写法，不能为了排版破坏匹配。
