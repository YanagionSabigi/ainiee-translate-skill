# 翻译预设与翻译模组

翻译模组保存一套可复用的翻译要求。你可以按书籍、领域、语言或读者命名，不必沿用程序给出的英文名称。默认保存位置如下；设置 `AINIEE_TRANSLATE_HOME` 时，只替换最外层的 `.ainiee-translate` 目录。

```text
~/.ainiee-translate/
└── 翻译预设/
    └── 翻译模组/
        └── 你取的模组名/
            ├── 初次翻译.md
            ├── 预设参数.md
            ├── 润色校对.md
            ├── 语言风格.md
            ├── glossary.locked.json
            ├── glossary.locked.schema.json
            ├── glossary.locked.policy.json
            └── module.json
```

前六项是供你维护的主要内容。`初次翻译.md` 说明准确性、结构与初翻要求；`润色校对.md` 说明对照原文的修改尺度；`语言风格.md` 说明语气、句法与示例。`预设参数.md` 明确标点符号模式和人名翻译模式，不设置默认输出格式。术语表和其 Schema 一并属于模组；另外两个文件用于政策绑定和模组元数据。

```text
python -m ainiee_translate.module create 我的模组 --source-language en --target-language zh --punctuation-mode full --name-mode D
python -m ainiee_translate.module load 我的模组 --work 我的翻译项目
```

新建时前三种提示／风格文档为空，术语表与 Schema 为可校验的空骨架。预设参数采用下面两行，修改时保留标签，填写一个值：

```text
- 标点符号模式：full
- 人名翻译模式：D
```

`full`／`half` 分别为全角／半角；A、B、C、D 的含义见[人名翻译模式](人名翻译模式.md)。每次任务另行选择输出格式与模板，见[输出模板选择](输出模板选择.md)。模组不会替你决定 EPUB、LaTeX 或其他输出。

加载到项目时，初翻、润色与风格分别对应 `work/user_prompt.md`、`work/polish_prompt.md`、`work/style.md`，预设参数和术语 Schema 也一并复制。Agent 在翻译、润色前读取这些文件，并把 PDF 结构项目的标点选择同步到审阅配置。已有文件先备份；修改模组后需重新加载，已有译文不会自动改变。

旧的 `modules/<名字>` 与英文提示词文件仍可读取，加载不会改动旧模组。切换时，所选模组没有提供的提示词、风格、预设或词表文件，会在项目中先备份再移除，避免沿用上一模组的规则。新同名模组优先；不自动批量迁移旧目录，避免影响正在进行的项目。旧 AiNiee profile 可以导入到新中文目录，但词表仍保持原格式，需经审核才能升级到新 Schema。

仓库中的技能目录保留 `翻译预设/翻译模组/通用翻译预设模组/` 空位置，暂不填入内容，也不将其作为可直接加载的成品模组。可用上面的命令在自己的配置位置建立并命名模组。
