# PDF 转 EPUB 转换工程

转换流程与命令见 [SKILL.md](SKILL.md)。

## 引文排版

构建 EPUB 时，程序会识别以“某某说：”“某某说道：”“某书写道：”
“某某指出：”“某某论述道：”“某某记载道：”结尾的正文段落。
紧邻其后的一个自然段，无论是否带引号，均按引文排版：

- 淡绿色（`#79a88a`）。
- 字号为正文的 90%，随阅读器字号设置一起缩放。
- 优先使用仿宋字体（FangSong / STFangsong / 仿宋）。

全角和半角冒号均支持，引导语中的行内字体样式和末尾注释标记不影响识别。
只处理紧邻的一个段落，不跨标题、列表、章或注释边界，不延伸到后续正文。
“也就是说：”“换句话说：”和普通冒号说明不作为引用引导语。
引文本身的文字、引号、强调样式、注释跳转和回跳均保留。
已经在审校计划中标为 `kind: "quote"` 的引文也采用同一套样式。

识别在构建时执行，现有 `book.json` 重新构建即可应用，不必重新 OCR。
程序不改写原始提取、审校计划或 `book.json`；自动识别的段落 ID 会写入
`conversion-report.json` 的 `introduced_quote_blocks`，便于核对。
这是基于引导语的启发式识别，其他表达或连续多段引文仍需审校时标为 `quote`。

字体依赖阅读设备已安装的字体；没有仿宋时退回设备衬线字体。
阅读器强制使用自定义字体、颜色或字号时，可能覆盖书籍样式。
已输出的 EPUB 需要重新构建，才会应用本次功能。

## 注释、化学式与插图

- 所有注释回跳链接固定显示「返回原文」，保留每一处回跳目标。
- 审校标记的化学式文字支持原子数下标、离子电荷上标和 `⇆` 可逆符号；
  例如 `H₂O`、`Fe³⁺`、`SO₄²⁻`，普通正文数字保持原样。
- 正文图片连同图注移到首次明确提及它的段落之后。独立提取的图注也可明确绑定，
  移动后保留文字、样式和注释链接；不跨章猜配，不能定位时保留输入并阻止成品构建。

审校字段和例子见 [content-layout.md](references/content-layout.md)。
已有工程须先补齐图片对应关系及化学式审校标记，再重新构建；不必重新 OCR。

## 微信读书兼容修复

原创 [兼容示例与源稿](../assets/template/epub/weread-compat/README.md) 演示目录、跨文件脚注往返及去灰底引文。
处理规则与验收条件见 [操作参考](references/weread.md)。

构建时同时输出 EPUB 3 导航和旧式 NCX 目录，两者使用相同的标题、层级、顺序和跳转目标。
NCX 只复制导航，不扫描正文链接，脚注引用与章末注释不会因此进入目录。

对已有 EPUB，可生成独立测试副本，无需重新提取或转换文字：

```powershell
python scripts/epub_weread.py "原书.epub" "目录测试.epub" --test-label "微信读书测试A"
python scripts/epub_weread.py "原书.epub" "无灰底测试.epub" --plain-callouts --test-label "微信读书测试B"
```

默认只补兼容目录；已有 NCX 时按 EPUB 3 导航重新生成并绑定。原文件及已有输出不覆盖。
`--test-label` 在测试副本的书名中添加标签，并生成新的书籍标识，便于重新导入比较；
不提供时保留书名和标识。此选项不迁移微信读书里的阅读进度、划线或想法。
有加密或字体混淆资源时，拒绝使用 `--test-label` 更改标识，避免字体解码失效；
省略该选项仍可补目录。

`--plain-callouts` 仅移除 `div` 上的 `bgc_HEX` 背景类；保留文字、自然段、其他样式、
脚注与图片链接、表格单元格底色。它针对保留出版社背景类的恢复版 EPUB，
不处理任意行内背景或其他 CSS 命名约定。该选项用于比较灰底被微信读书拆到各段后的表现。

已在本地样书的微信读书导入中完成手机实测：脚注、角标及文件名异常目录均消失，
用户确认采用去灰底后的引文、署名与翻页方案。50项测试、EPUBCheck和本轮兼容修改的独立复核通过。
其他书籍的自动分片规则及阅读器表现需分别验证。诊断证据与步骤见
[weread-fix.md](docs/weread-fix.md)。

如果实测出现 `文件名_1` 这样的无名续段，可按现有目录标题显式分开过长的章节文件：

```powershell
python scripts/epub_weread.py "原书.epub" "分段测试.epub" --split-at "EPUB/chapter.xhtml#section-id"
```

`--split-at` 可重复，每个原文件只支持一个拆点。路径是 ZIP 内路径；拆点必须已经列入
EPUB 的 TOC，且是 body 或其匿名 div 下的直接标题。只移动完整块，保留 ID，重写
注释、回跳、正文和目录链接；不增加目录项，不改脚注内容或编号。不自动猜切点、
字数阈值或章节归属。带有媒体叠加层的书籍拒绝拆分；其他非 XHTML 外部依赖需要另行核对。
