# 注释回跳、化学式和正文插图

## 注释回跳

所有注释的回跳链接都显示「返回原文」，不受旧计划 `labels.return` 的值影响。
同一注释有多个引用时，每处引用仍有独立回跳链接和正确目标；可见文字相同，
辅助标签区分引用次序。图片或图注移动后，publication 模式按最终阅读顺序重新编号。

## 化学式文字

在审校计划中标记经过源文核对的完整化学式文字项：

```json
{"text":"Fe3+ + SO4^2- <=> FeSO4", "chemistry":true,
 "evidence":"源图中原子数、电荷和可逆反应符号均已核对"}
```

构建输出 `Fe³⁺ + SO₄²⁻ ⇆ FeSO₄`。支持 `H2O`、`NH4+`、`Ca(OH)2`、
`[Fe(CN)6]3-`、`CuSO4·5H2O`，前置反应系数和结晶水系数保留基线。
已有 Unicode 上下标保留；`<=>`、`<->`、`⇌` 可逆符号统一为 `⇆`，`->` 转为 `→`。
核素质量数用显式 `^14C` 表示，输出 `¹⁴C`；裸 `14C` 不自动视为核素标记。
多原子离子的电荷建议使用显式 `^`，例如 `O2^-`、`SO4^2-`。
`SO42-` 等有歧义的写法保持原样，须回看源文修复；不能靠自动排版猜电荷或配平。
不支持的式子保持原样，审校时改用源文确认的 Unicode、已有上下标样式或公式资源。

也可在 `line` 源切片项上使用 `chemistry:true` 和 `evidence`；同一化学式跨不同样式时，
提供经过源核验的完整文字项，避免片段拼接使原子数与电荷歧义。未标注的普通文字、
年份、章节数字和数学表达式不被化学排版改写。原始提取和审校 JSON 不会被构建改写。

## 图片、提及段落和图注

每个 `kind:"figure"` 的图片需要一个同章或同注释容器的正文段落作为位置锚点。
自动识别 `图1`、`图 1-2`、`图1.2`、`Figure 1`、`Fig. 1` 等完整图号，
`图1` 不匹配 `图10`。图号可来自图注开头、已绑定的独立图注或 `figure_label`。
正文明确链接也可指定目标：`{"link":"figure-1","text":"图1","evidence":"源文明确指图"}`。
段落与引文可作为锚点，标题、列表、图注本身不作为定位段落，不跨章猜配。
多次提及时取首次明确提及；多个图片对应同一段落时保留图片原有相对次序。

没有可自动匹配的图号、图号在同一容器内重复或需经源图消歧时，审校指定位置：

```json
{"id":"figure-1", "kind":"figure", "after_block":"paragraph-12",
 "placement_evidence":"paragraph-12 明确讨论此图，图号与源图已核对",
 "asset":{"id":"image-1","path":"assets/image-1.png","alt":"原图说明"},
 "inline":[{"text":"图1：完整图注。","evidence":"原图图注已核对"}]}
```

`after_block` 显式定位优先于自动定位。图片只输出一次，放在该段落结束后，
紧随其后的原正文段落之前。图片及图注作为同一个 `figure/figcaption` 输出，
样式请求阅读器避免把图片与图注分页拆开；超高图片和不同阅读器仍需视觉核验。
同一图号对应不同图片时逐图指定位置并核验其源资源，不能仅靠重复图号推断关联。

若图注是单独提取出的段落，在该段落写明 `caption_for`：

```json
{"id":"caption-1", "kind":"paragraph", "caption_for":"figure-1",
 "sources":["source-line-caption"]}
```

构建将它纳入对应图片的 `figcaption`，保留段落 ID、完整文字、样式、公式及注释链接，
不在原位置再输出。图片块 `inline` 中已有的图注不要再次作为独立段落重复保留；
`caption_for` 必须绑定同容器实际存在的图片。没有明确归属的图注、冲突的图号或无
提及段落的图片会阻止构建，原输入、图片资源和已存在的 EPUB 均保留，待审校修复。

核对 `conversion-report.json.figure_placements`：逐图检查 `figure`、`container`、
`after_block`、`method`、`caption_blocks` 和可用的图号。对照源图确认图片数量、
图注对应关系和顺序，并检查每个图片资源在成品中可见。封面、封底、独立公式、
表格图片和行内公式不使用此插图移动规则。
