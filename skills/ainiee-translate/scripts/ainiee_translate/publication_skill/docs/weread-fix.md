## 证据与边界

受影响的恢复版 EPUB 有 89 条 EPUB 3 导航、518 个正文注释引用、518 个章末注释。微信读书只读接口返回 1121 个章节，其中 518 项为纯数字、518 项为 `footnote-*`。恢复脚本主动删除了 NCX，通用生成器也仅输出 EPUB 3 导航。数量对应支持“缺少兼容目录时导入器回退扫描链接”的假设，但导入器实现不可见，必须用手机重新导入验证因果。

截图中的灰底对应一个包含多段引文、对话和署名的 `div.bgc_cccccc`。本地结构没有逐段背景，截图显示微信读书将背景作用到各段，是否发生内容遗漏或分页截断尚未证实。先提供可选去底色版本，保持自然段，不用禁止整块跨页规避。
