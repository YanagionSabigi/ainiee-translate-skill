# AiNiee 2.2.0 · 术语派生类审核与工作台更新

本版基于 Review Workbench 0.3.0，整理扫描术语表初审，并保留微信读书反馈校对流程。

## 术语表初审

- 默认展开「术语信息」，集中显示原词、分类领域、一句原文上下文和 PDF 物理页码。
- 左右比较框仅显示当前译名与建议译名，移除重复原词、分类说明和固定提示。
- 普通术语放入目录子项；派生词按基础词单独成类，仅在派生类中显示顶部预览和「同意一类」。
- 目录与顶部预览上排原词、下排当前暂定译名；明确选择建议或手动修改后同步显示。
- 「同意一类」保留本类各项暂定译名，覆盖后续页，跳过必审项、已有人工草稿和已提交项；仍可逐项修改。搜索或状态筛选期间禁用整类批准，避免扩大处理范围。
- 新增 `workbench glossary --review-data`，通过独立 JSON 提供上下文、页码和语义派生关系；缺证据的条目必须逐项审核，不根据词形猜测关系。

## 微信读书与通用工作台

保留阅读选区与想法的独立区块、手机断行整理和原始引用定位。同步 0.3.0 的前后项快捷键、状态色、目录图标和通用材料整页批准，并修复空格键影响按钮激活的问题。

旧冻结审核包继续使用原绑定；获得新术语布局需要准备新一轮并重新导出审核 ZIP。完整技能安装 ZIP 与具体项目的审核 ZIP 用途不同。人工决定仍需正式提交，再由 Agent 核验当前稿并写回。
