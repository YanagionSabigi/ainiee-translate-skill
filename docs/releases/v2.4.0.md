# AiNiee 2.4.0 · 连续阅读模板

- Rosé Pine book 使用 Dawn 页面底色，定理与推论采用协调的 Overlay 浅米粉色，命题、引理及定义保持轻量排版。附带同内容白底版。
- 减轻证明、引用、例及习题的框体装饰；修正章标题、页眉编号与跨页陈述的引用定位。
- 数译 book、article 恢复简洁风格，book 的数学陈述题头后换行，证明保留 QED 方块。
- 四份模板均包含三级无序列表和长条目折行测试；Rosé Pine book 增加连续阅读样章及可选分页压力测试。
- 技能内附 LaTeX 后端与标点规则，并提供模板使用时的必读入口。
- 保留 2.3.0 的通用术语表、审核工作台及 PDF/EPUB 出版功能。

## 使用

模板路径：`scripts/ainiee_translate/assets/template/tex/`。Rosé Pine book 的 `main.tex` 为 Dawn 版本，`white.tex` 为白底版本；运行 `python build_previews.py` 可重建预览。字体与 XeLaTeX 编译环境需另行准备。模板仍是独立可编辑素材，尚未替换自动导出器。Typst 目录继续保留，未新增 Typst 模板。
