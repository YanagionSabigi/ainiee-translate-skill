# AiNiee 2.3.0 · 通用术语表与 PDF 模板

## 通用术语表与 module

- 新建 module 使用统一的人名、术语、缩写 Schema，支持语言形式、稳定 ID、别名、词形、引用与组合译名。
- 保留 A 汉化、B 拉丁转写、C 源语言、D 按姓名体系处理四种模式，默认 D；资料不足时保留源文并报告待核实，不猜造人名。
- 不预置领域分类或词库。建议根据当前文献提前生成、核对分类，空分类也可使用。
- module 加载、过滤子表、PDF／阅读校对携带哈希绑定的政策快照；工作台按原始字段回写，保留旧表和 profile 兼容。

## 新 PDF 模板与出版组件

- 附带 Rosé Pine 和数译风格各一套 book、article，共四套独立 XeLaTeX 模板，包含可编辑 `main.tex` 和 PDF 预览。
- 技能包内路径：`scripts/ainiee_translate/assets/template/tex/`。复制所需示例目录后编译两遍；本机需要 XeLaTeX 及相应宏包，字体与编译器不随包分发。
- 四套示例均完成两遍编译检查及 PDF 预览检查。它们供独立改编使用，尚未替换自动导出器的模板；已有 LaTeX／Typst 自动导出器继续可用。
- 保留参考来源、MIT 许可与署名。EPUB 组件改进图位、注释编号、分片与微信读书兼容处理，并附带公开示例。

## 下载与安装

- `ainiee-translate-v2.3.0.zip`：完整技能安装包，含运行脚本、Schema、工作台与上述模板。备份旧技能后替换整个 `ainiee-translate` 目录。
- `ainiee_translate-2.3.0-py3-none-any.whl`：Python 包；不能代替完整技能安装包。
- `release-manifest.json`、`SHA256SUMS`：文件和发布资产的 SHA-256 校验信息。

Python 要求 3.12 或更新版本。旧项目和旧审核包不自动迁移；新词表复制时须同时携带配套 `.policy.json` 文件。

本轮验证：334 项 Python 回归、17 项前端测试通过；四套 TeX 模板均编译两遍通过；ZIP／wheel 资源和校验清单验证通过。
