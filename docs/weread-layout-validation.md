- 两项分别为独立 section 和二级标题；桌面左右等宽并列，与下方原版/建议面板对齐，窄于 640px 时上下排列。多条阅读想法在同一个想法面板里逐条保留；待关联想法单独标明。
- 按用户后续要求，页面删除断行处理说明，只在技能指南记录规则。

- 只投影显示内容，不改动原始笔记、冻结 package、哈希、候选译文或业务缓存。移除旧标题前缀、合并 CRLF 后，引用仍转换回原始 Unicode 码点偏移及原始片段，服务端继续按原始材料校验。
